# 拍研所 · 乒乓球拍 3D 配置器

Three.js 驱动的乒乓球拍配置器。自由组合底板与胶皮，实时 3D 预览，并给出性能评估与 ITTF 合规性检查。

## 运行

任选一种起一个静态服务（用了 ES module + importmap，不能直接双击 `file://` 打开）：

```bash
cd racket-lab
python3 -m http.server 8811
# 浏览器打开 http://127.0.0.1:8811
```

Three.js 通过 importmap 从 unpkg 加载（`three@0.169.0`），首次打开需要联网。

## 3D 是怎么建的

- **底板逐层挤出**：不是一块实心木头，而是按结构表把每一层单独 `ExtrudeGeometry` 再沿 Z 叠起来。
  所以侧面看到的木层/芳碳层是真实几何，「外置芳碳」与「内置芳碳」的碳层位置差别肉眼可辨
  —— 点「层剖」视角可以直接数层。
- **胶皮分两层**：海绵层 + 面胶层，边缘能看到海绵色带。
- **颗粒胶皮真实铺颗粒**：正胶/生胶/长胶用 `InstancedMesh` 按六方堆积撒颗粒，
  落点用射线法在拍面轮廓内做筛选；反胶与防弧则是光滑面（真实结构就是颗粒朝内）。
- **面胶质感分档**：粘性胶（狂飙、Dignics 09C、K3 等）走强清漆 + 低粗糙度，
  防弧走全哑光，普通反胶介于两者之间。

## 性能评估模型

四项指标拆成「底板贡献 + 胶皮贡献」的堆叠条，权重如下：

| 指标 | 底板 | 胶皮 | 说明 |
|---|---|---|---|
| 速度 | 45% | 55% | 胶皮出球速度占主导 |
| 旋转 | 25% | 75% | 旋转几乎由面胶决定 |
| 控制 | 45% | 55% | 底板支撑与胶皮容错各占一半 |
| 硬度 | 40% | 60% | 海绵硬度权重更高 |

**数值口径**：所有 speed / spin / control / hard 都是本站内部的 0–100 归一化指数，
由公开评测与产品定位换算，用于站内横向比较。各厂商官方刻度互不通用
（蝴蝶自家刻度、德系 47.5°、红双喜 39 度是四套体系），所以不直接引用任何一家的官方数字。

搭配点评、打法归类均从这套指数推导，属于经验性启发式判断，不是精确物理模型。

## ITTF 合规性检查

- **两面必须一面黑 + 另一面鲜艳色** —— 违反时判红并说明原因（这条是真规则，不是建议）
- 整拍重量 > 190g 提示偏重
- 正反手胶皮硬度差 > 26 档提示手感差异

## 尺寸口径（已对齐真拍，可核对）

| 部位 | 模型 | 真拍参考 |
|---|---|---|
| 有效拍面（柄根以上） | 148 × 157 | 150 × 157 |
| 板厚 | 5.6 – 6.8 | 同 |
| 整拍长 | 259 – 263（视柄型） | ~260 |
| 拍面底端宽度（拍肩） | 90 | 缓收，留明显拍肩 |
| FL 柄宽 根 / 腰 / 尾 | 30 / 26 / 34 | 30 / 26 / 34 |
| FL 柄长 | 103 | 100 |
| 柄厚 | 23.5（直板 17.5 / 20.5） | 22 – 25 |
| 芳碳层位置 | 距表面 0.54 / 0.75mm（外置） | 外置结构 |

柄型规格表里写的是**成品总宽**，构建时会自动扣掉倒角量 —— 所以标称值就等于量出来的值。

**「拍肩」是个容易被忽略的关键**：真拍板面到手柄是缓收，在柄两侧留出明显的翼状区域
（Viscaria 的 wings 比 HL5 大，同样重量下板面更短）。早期版本一路收到 24mm 的尖，
所以怎么调都像棒棒糖。现在收到 90mm，留出拍肩。

## 手柄差异

43 块底板的手柄**不是同一个模子换颜色**，而是每块底板各有一套手柄样式：

| 布局 | 说明 | 例子 |
|---|---|---|
| `center` | 居中一条对比饰条 | Viscaria、张继科 ZLC、狂飙龙 5 |
| `twin` | 左右对称两条 | 波尔 ALC、樊振东 ALC、YEO |
| `edge` | 靠边两条深色 | 波尔 ZLC、张本智和 ZLC |
| `trio` | 不对称三条 | 张本智和 ALC、阿姆塔特 |
| `line` | 素木 + 一道细线 | 科贝尔、黑檀 7、木吉他 |

标牌分 圆 / 椭圆 / 无 三种：蝴蝶系用金属圆牌，红双喜与斯帝卡系多为素木无牌。

> **注意**：手柄样式是按**各品牌手柄的典型做法**归纳的风格化还原（蝴蝶＝圆金属牌＋
> 对比饰条，斯帝卡＝素木细线，红双喜＝彩色条无牌），**不是逐型号对着实物描的**。
> 颜色取自每块底板自己的柄色数据。要精确到型号需要实物照片逐一对版。

## 已知取舍

- 拍面轮廓是统一的 148×157 板形，没有做各家、各型号的板形差异（真拍同一尺寸下
  拍肩大小、收腰快慢也不同 —— 这正是 Viscaria 和 HL5 的区别所在）。
- 直板只影响柄型，没有做直板专用板形。
- 手柄样式按品牌典型做法归纳，未逐型号对版（见上）。
- 胶皮颜色只开放该型号实际市售的颜色（比如 Tenergy 只有黑/红），不是任意可选。
- 芳碳层的厚度按 0.22mm（纤维 + 浸渍树脂的复合层）。单看纤维布会更薄，但 0.15mm
  在 1:1 尺度下只有 3~4 像素，侧面那道深色线会完全看不见。
- 渲染是风格化产品展示，不是照片级写实。
