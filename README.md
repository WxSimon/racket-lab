# 拍研所 · 乒乓球拍 3D 配置器

Three.js 驱动的乒乓球拍配置器。自由组合底板与胶皮，实时 3D 预览，并给出性能评估与 ITTF 合规性检查。

## 运行

任选一种起一个静态服务（用了 ES module + importmap，不能直接双击 `file://` 打开）：

```bash
cd racket-lab
python3 -m http.server 8811
# 浏览器打开 http://127.0.0.1:8811
```

Three.js 通过 importmap 从 unpkg 加载（`three@0.169.0`），首次打开需要联网。

## 3D 是怎么建的

- **底板逐层挤出**：不是一块实心木头，而是按结构表把每一层单独 `ExtrudeGeometry` 再沿 Z 叠起来。
  所以侧面看到的木层/芳碳层是真实几何，「外置芳碳」与「内置芳碳」的碳层位置差别肉眼可辨
  —— 点「层剖」视角可以直接数层。
- **胶皮分两层**：海绵层 + 面胶层，边缘能看到海绵色带。
- **颗粒胶皮真实铺颗粒**：正胶/生胶/长胶用 `InstancedMesh` 按六方堆积撒颗粒，
  落点用射线法在拍面轮廓内做筛选；反胶与防弧则是光滑面（真实结构就是颗粒朝内）。
- **面胶质感分档**：粘性胶（狂飙、Dignics 09C、K3 等）走强清漆 + 低粗糙度，
  防弧走全哑光，普通反胶介于两者之间。

## 性能评估模型

四项指标拆成「底板贡献 + 胶皮贡献」的堆叠条，权重如下：

| 指标 | 底板 | 胶皮 | 说明 |
|---|---|---|---|
| 速度 | 45% | 55% | 胶皮出球速度占主导 |
| 旋转 | 25% | 75% | 旋转几乎由面胶决定 |
| 控制 | 45% | 55% | 底板支撑与胶皮容错各占一半 |
| 硬度 | 40% | 60% | 海绵硬度权重更高 |

**数值口径**：所有 speed / spin / control / hard 都是本站内部的 0–100 归一化指数，
由公开评测与产品定位换算，用于站内横向比较。各厂商官方刻度互不通用
（蝴蝶自家刻度、德系 47.5°、红双喜 39 度是四套体系），所以不直接引用任何一家的官方数字。

搭配点评、打法归类均从这套指数推导，属于经验性启发式判断，不是精确物理模型。

## ITTF 合规性检查

- **两面必须一面黑 + 另一面鲜艳色** —— 违反时判红并说明原因（这条是真规则，不是建议）
- 整拍重量 > 190g 提示偏重
- 正反手胶皮硬度差 > 26 档提示手感差异

可以直接查场景树和当前配置。

## 已知取舍

- 拍柄长度、柄型轮廓是按实物比例近似，未逐一比对各家模具。
- 胶皮颜色只开放该型号实际市售的颜色（比如 Tenergy 只有黑/红），不是任意可选。
- 直板只影响柄型，拍面轮廓仍沿用统一的 150×158 板形，没有做直板专用板形。
